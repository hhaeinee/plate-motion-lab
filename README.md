# 손으로 만드는 판의 경계 — Plate Motion Lab (데모)

웹캠 앞에서 두 손을 움직이면 각 손이 하나의 **판**이 되고, 두 손의 **상대 운동**에 따라
발산형 · 수렴형 · 보존형 경계와 그에 따른 지각 변동이 실시간으로 시각화되는
중학교 과학(2022 개정 교육과정) 탐구용 학습 웹앱입니다.

`plate_boundary_mediapipe_PRD.md` 를 바탕으로 만든 **데모 버전**이며, 미션 모드까지 포함되어 있습니다.

---

## 1. 실행 방법

이 앱은 카메라를 사용하므로 **`index.html` 을 더블클릭해서 여는 방식(`file://`)으로는 카메라가 켜지지 않습니다.**
브라우저가 카메라를 허용하는 곳은 `https://` 또는 `localhost` 뿐입니다.

### 방법 A — 로컬 서버 (권장)

폴더에서 아래 중 하나를 실행한 뒤 브라우저에서 주소를 엽니다.

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

→ 브라우저에서 `http://localhost:8000` 접속

### 방법 B — VS Code Live Server 확장

`index.html` 우클릭 → **Open with Live Server**

### 방법 C — 카메라 없이 사용

툴바의 **손 없이 조작** 버튼을 켜면 서버 없이도(파일 더블클릭 포함) 모든 기능을 체험할 수 있습니다.
화면의 두 원을 마우스로 끌거나 방향키로 움직이면 손과 똑같이 동작합니다.

## 2. 카메라 권한 허용 방법

1. **카메라 시작** 버튼을 누르면 브라우저가 권한을 물어봅니다 → **허용**
2. 실수로 차단했다면 주소창 왼쪽의 자물쇠(또는 카메라) 아이콘 → **카메라 → 허용** → 새로고침
3. 다른 프로그램(줌, 팀즈 등)이 카메라를 점유하고 있으면 먼저 종료해 주세요

---

## 3. 조작 방법

| 동작 | 판의 상대 운동 | 결과 |
|---|---|---|
| 두 손을 **양쪽으로 벌린다** | 서로 멀어짐 | **발산형 경계** — 해령, 마그마 상승, 새 지각 생성 |
| 두 손을 **가운데로 모은다** | 서로 가까워짐 | **수렴형 경계** — 판 종류에 따라 해구·화산 또는 습곡 산맥 |
| 두 손을 **위아래로 엇갈리게** 움직인다 | 서로 어긋남 | **보존형 경계** — 응력 축적 → 지진 |

- 화면상 **왼쪽 손 = 판 A(파랑)**, **오른쪽 손 = 판 B(주황)**
- 수렴형 경계에서는 중앙 아래의 **판 구성 선택**(해양–대륙 / 해양–해양 / 대륙–대륙)에 따라 결과가 달라집니다
- 판 경계는 **절대 방향이 아니라 두 판의 상대 운동**으로 판별하므로, 한 손만 움직여도 경계가 만들어집니다

### 툴바

| 버튼 | 기능 |
|---|---|
| 카메라 시작 | 웹캠 + 손 인식 모델 로드 |
| 자유 탐구 / 미션 모드 | 모드 전환 |
| 초기화 | 판 위치·응력·미션·애니메이션 초기화 |
| 설명 보기 | 조작법과 개념 요약 |
| 손 없이 조작 | 마우스·키보드 폴백 모드 |
| 랜드마크 | 손 뼈대 표시 ON/OFF |
| 소리 | 지진·성공 효과음 ON/OFF |
| 디버그 | 판정 수치(separation / shear / stress 등) 표시 |

## 4. 미션 (5개)

1. **발산형 경계 만들기** — 발산형 1초 이상 유지 (예측 질문 포함)
2. **해양판–대륙판 수렴형 경계 만들기** — 판 구성 자동 설정 후 1초 유지
3. **화산보다 거대한 산맥이 만들어지는 경계** — 학생이 판 구성을 직접 선택 (예측 질문 포함)
4. **보존형 경계 만들기** — 보존형 1초 이상 유지
5. **응력을 쌓아 지진 일으키기** — 보존형 유지 + 응력 85% 초과 → 지진 발생

---

## 5. 수업에서 쓰는 방법

1. 교사가 시연으로 **자유 탐구**에서 세 경계를 한 번씩 보여 줍니다.
2. 학생이 직접 손으로 세 경계를 만들며 우측 **개념 정리 카드**를 읽습니다.
3. 경계를 하나 만들 때마다 **관찰 기록 추가**를 눌러 표를 채웁니다.
4. **미션 모드**로 전환해 5개 미션을 순서대로 수행합니다.
5. 마무리로 "왜 모든 수렴형 경계에서 화산이 생기지 않을까?"를 토의합니다.

한 대의 노트북을 교탁에 두고 학생이 번갈아 나와 조작하는 방식이 가장 원활합니다.
(손 인식은 한 번에 두 손만 사용하므로 여러 명이 동시에 화면에 들어오면 인식이 흔들립니다.)

## 6. 기술 구성

- **MediaPipe Tasks Vision `HandLandmarker`** (`@mediapipe/tasks-vision@0.10.14`)
  - **로컬 `vendor/` 폴더 우선** → 없으면 자동으로 CDN 사용 (인터넷 없이도 동작)
  - 모델: `hand_landmarker.task` (float16, 약 7.6 MB)
  - GPU delegate 실패 시 자동으로 CPU delegate로 재시도
  - 어느 쪽에서 불러왔는지는 **디버그** 패널의 `assets` 항목에서 확인할 수 있습니다
- **Canvas 2D** 렌더링, `requestAnimationFrame` 단일 루프
- 추론은 **새 비디오 프레임이 들어왔을 때만** 실행 (`video.currentTime` 비교)
- DOM은 **값이 바뀔 때만** 갱신
- 빌드 도구·프레임워크 없음

### 폴더 구조

```
index.html            화면 구조
style.css             스타일
script.js             전체 로직
serve.ps1             로컬 서버 (Windows PowerShell)
README.md             이 문서
vendor/
  vision_bundle.mjs                   MediaPipe Tasks Vision (ESM)
  wasm/vision_wasm_internal.js|wasm   WASM 런타임 (SIMD)
  wasm/vision_wasm_nosimd_internal.*  WASM 런타임 (구형 CPU용)
  models/hand_landmarker.task         손 랜드마크 모델
```

`vendor/` 를 통째로 지우면 자동으로 CDN에서 내려받아 동작합니다(인터넷 필요).

### 판정 알고리즘 요약

1. 각 손의 손바닥 중심 = 랜드마크 `0, 5, 9, 13, 17`의 평균
2. mirror 변환은 `toUserX()` **한 함수에서만** 처리
3. EMA 평활화 + 이상치(0.25 이상 점프) 제거 + 900ms 히스토리 버퍼
4. 최근 220ms 평균 − 과거 420~780ms 평균 = 이동 벡터
5. **두 손을 잇는 경계축**을 기준으로 상대 이동 벡터를 분해
   - 축 성분(`separation`) → 발산 / 수렴
   - 수직 성분(`shear`) → 보존형
6. 후보 상태가 450ms 이상 유지될 때만 상태 전환 (debounce)

임계값은 모두 `script.js` 최상단 `CONFIG` 객체에 모여 있습니다. 교실 카메라 환경에 맞춰 조정하세요.

## 8. 알려진 한계

- **보존형 경계**가 세 경계 중 가장 판별이 까다롭습니다. 손을 위아래로 크고 분명하게 엇갈리게 움직여야 합니다.
  (좌우 거리가 함께 변하면 발산·수렴으로 판정될 수 있습니다.)
- MediaPipe의 좌/우 손 라벨은 손등이 보이면 자주 뒤집히므로, 이 앱은 라벨을 쓰지 않고
  **화면상 x좌표가 작은 쪽을 판 A**로 고정합니다. 두 손을 좌우로 교차시키면 판 A/B가 바뀝니다.
- 카메라 앞에 **다른 사람의 손**이 들어오면 그 손이 판으로 인식될 수 있습니다.
- `vendor/` 폴더가 함께 있으면 **인터넷 없이도 동작**합니다. 폴더를 통째로 USB에 담아
  학교 노트북에 옮긴 뒤 `serve.ps1` 로 실행하면 됩니다.
  (`vendor/` 가 없고 네트워크도 막혀 있으면 **손 없이 조작** 모드를 사용하세요.)
- `vendor/` 포함 시 전체 용량은 약 26 MB입니다.
- 보존형 경계는 단면도로 표현할 수 없어 **평면도(위에서 본 모습)** 로 자동 전환됩니다.
- 관찰 기록은 브라우저 세션 내 배열로만 저장되며 새로고침하면 사라집니다.

## 9. 과학적 주의 사항 (수업 중 강조할 점)

- 이 시뮬레이션의 속도·수치는 모두 **모의값**입니다. **실제 판은 1년에 수 cm 정도**로 움직입니다.
- **모든 수렴형 경계에서 화산이 생기지는 않습니다.** 대륙판끼리 충돌하면 습곡 산맥이 중심입니다.
- 보존형 경계에서는 지각이 생성·소멸되지 않고 **수평 이동과 지진**이 핵심입니다.
- 지진이 판 경계에서만 발생하는 것은 아니지만, **큰 지각 활동은 대부분 판 경계 부근에 집중**됩니다.
- 판은 액체 위에 떠 있는 얇은 판자가 아니라, 맨틀 최상부를 포함한 **두꺼운 암석권 조각**입니다.
